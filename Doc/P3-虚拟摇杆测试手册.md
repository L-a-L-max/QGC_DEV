## 2. 环境准备

### 2.1 启动 PX4 SITL

**单机：**
```bash
cd ~/PX4-Autopilot
make px4_sitl gz_x500
```

**多机（批量启动）：**
```bash
# 参考 PX4 多机仿真文档，启动 3 台
# 各实例 namespace: px4_1, px4_2, px4_3
Tools/simulation/gz/sitl_multiple_run.sh -n 3 -m x500
```

### 2.2 启动 MicroXRCE-DDS Agent

**单机：**
```bash
MicroXRCEAgent udp4 -p 8888
```

**多机（每个实例一个 Agent）：**
```bash
MicroXRCEAgent udp4 -p 8888    # px4_1
MicroXRCEAgent udp4 -p 8889    # px4_2
MicroXRCEAgent udp4 -p 8890    # px4_3
```

```bash
source /opt/ros/humble/setup.bash  # 或你的 ROS2 版本

```

如果 `px4_msgs` 没有安装：
```bash

cd ~/ros2_ws/src

cd ~/ros2_ws
colcon build --packages-select px4_msgs
source install/setup.bash

# 方法二：apt 安装（如果有对应版本）
sudo apt install ros-humble-px4-msgs
```

## 3. 方法一：ros2 topic pub 快速测试

最简单的方式，一行命令直接发布话题。

### 3.1 发送中位值（悬停/无动作）

```bash
ros2 topic pub /fmu/in/manual_control_input px4_msgs/msg/ManualControlSetpoint \
  "{timestamp: 0, timestamp_sample: 0, valid: true, data_source: 2, \
    roll: 0.0, pitch: 0.0, yaw: 0.0, throttle: 0.0, \
    flaps: 0.0, aux1: 0.0, aux2: 0.0, aux3: 0.0, aux4: 0.0, aux5: 0.0, aux6: 0.0, \
    sticks_moving: false, buttons: 0}" \
  --rate 25
```

### 3.2 向前飞（pitch=-0.3）

```bash
ros2 topic pub /fmu/in/manual_control_input px4_msgs/msg/ManualControlSetpoint \
  "{timestamp: 0, timestamp_sample: 0, valid: true, data_source: 2, \
    roll: 0.0, pitch: -0.3, yaw: 0.0, throttle: 0.0, \
    flaps: 0.0, aux1: 0.0, aux2: 0.0, aux3: 0.0, aux4: 0.0, aux5: 0.0, aux6: 0.0, \
    sticks_moving: true, buttons: 0}" \
  --rate 25
```

### 3.3 升高（throttle=0.5）

```bash
ros2 topic pub /fmu/in/manual_control_input px4_msgs/msg/ManualControlSetpoint \
  "{timestamp: 0, timestamp_sample: 0, valid: true, data_source: 2, \
    roll: 0.0, pitch: 0.0, yaw: 0.0, throttle: 0.5, \
    flaps: 0.0, aux1: 0.0, aux2: 0.0, aux3: 0.0, aux4: 0.0, aux5: 0.0, aux6: 0.0, \
    sticks_moving: true, buttons: 0}" \
  --rate 25
```

### 3.4 多机场景（指定 namespace）

```bash
# 控制 px4_2
ros2 topic pub /px4_2/fmu/in/manual_control_input px4_msgs/msg/ManualControlSetpoint \
  "{timestamp: 0, timestamp_sample: 0, valid: true, data_source: 2, \
    roll: 0.0, pitch: -0.3, yaw: 0.0, throttle: 0.0, \
    flaps: 0.0, aux1: 0.0, aux2: 0.0, aux3: 0.0, aux4: 0.0, aux5: 0.0, aux6: 0.0, \
    sticks_moving: true, buttons: 0}" \
  --rate 25
```

> **注意**：`ros2 topic pub` 按 Ctrl+C 停止后，PX4 会在几秒后进入 RC Lost 失控保护。
> 建议测试时先用中位值保持发送，再修改参数。

## 4. 方法二：Python 脚本键盘控制

使用 `Doc/test_manual_control.py` 脚本，支持实时键盘控制。

### 4.1 安装依赖

```bash
source /opt/ros/humble/setup.bash
pip3 install rclpy px4_msgs  # 如果通过 colcon 编译则 source 对应 setup.bash
```

### 4.2 运行脚本

```bash
cd ~/qgc_dev/Doc  # 或你的 qgroundcontrol/Doc 目录

# 单机
python3 test_manual_control.py

# 多机（控制 px4_2）
python3 test_manual_control.py --ns px4_2

# 自定义频率和步长
python3 test_manual_control.py --hz 50 --step 0.05

# 无 ROS2 环境（仅验证键盘映射，不实际发送）
python3 test_manual_control.py --no-ros
```

### 4.3 键盘映射

## 5. 方法三：QGC 虚拟摇杆

### 5.1 启用虚拟摇杆

1. 打开 QGC → **齿轮图标(Application Settings)** → **General**
2. 找到 **Virtual Joystick** 选项 → **打开开关**
3. 回到飞行界面

### 5.2 虚拟摇杆布局

飞行界面底部会出现两个半透明的摇杆区域：

```
┌──────────────────────────────────────┐
│           飞行画面 / 地图             │
│                                      │
│                                      │
│  ┌──────┐                ┌──────┐   │
│  │      │                │      │   │
│  │ 左摇杆│                │ 右摇杆│   │
│  │油门+偏│                │横滚+俯│   │
│  │航    │                │仰    │   │
│  └──────┘                └──────┘   │
└──────────────────────────────────────┘
```

| 摇杆 | 轴 | 操作 |
|------|---|------|
| 左摇杆 上下 | Throttle (油门) | 上=升高, 下=降低 |
| 左摇杆 左右 | Yaw (偏航) | 左=逆时针, 右=顺时针 |
| 右摇杆 上下 | Pitch (俯仰) | 上=前进, 下=后退 |
| 右摇杆 左右 | Roll (横滚) | 左=左移, 右=右移 |

### 5.3 QGC 数据流

```
触摸/鼠标拖动
    ↓
JoystickThumbPad.qml (触摸跟踪 → xAxis/yAxis)
    ↓
VirtualJoystick.qml (25Hz Timer)
    ↓
Vehicle::virtualTabletJoystickValue(roll, pitch, yaw, thrust)
    ↓
DDSManualControlPublisher::sendManualControl()
    ↓
DDS Topic: rt/{ns}/fmu/in/manual_control_input
    ↓
PX4 XRCE-DDS Agent → uORB: manual_control_input
    ↓
ManualControlSelector → ManualControl → FlightMode Controller
```

## 6. 完整操作流程

### 流程一：脚本直接控制（不依赖 QGC）

```
步骤 1: 启动 PX4 SITL
步骤 2: 启动 DDS Agent
步骤 3: 运行测试脚本
步骤 4: 按 3 (ARM)
步骤 5: 按 1 (起飞，等待 5 秒)
步骤 6: 按 T 升高油门，按 W/A/S/D 控制飞行
步骤 7: 按 2 降落 或 按 4 DISARM
```

**详细步骤：**

**步骤 1：启动 PX4 SITL**
```bash
cd ~/PX4-Autopilot
make px4_sitl gz_x500
```
等待出现 `pxh>` 提示符和 "Ready for takeoff!" 消息。

**步骤 2：启动 DDS Agent（新终端）**
```bash
MicroXRCEAgent udp4 -p 8888
```

**步骤 3：运行测试脚本（新终端）**
```bash
source /opt/ros/humble/setup.bash
# 如果 px4_msgs 是 colcon 编译的：
source ~/ros2_ws/install/setup.bash

python3 ~/qgc_dev/Doc/test_manual_control.py
```

**步骤 4：起飞**
- 按 `3` 发送 ARM 命令
- 等待 PX4 终端显示 "Armed by external command"
- 按 `1` 发送起飞命令（默认 2.5m）
- 等待无人机上升到目标高度

**步骤 5：手动控制飞行**

PX4 起飞后自动进入 Takeoff 模式，到达高度后切为 Loiter/Hold。此时需要在 PX4 终端手动切换到 Position 模式以接受手动控制输入：

```bash
# 在 PX4 nsh 终端中
commander mode posctl
```

然后在脚本窗口：
- 按 `W` - 向前飞
- 按 `S` - 向后飞
- 按 `A` - 向左飞
- 按 `D` - 向右飞
- 按 `T` - 升高
- 按 `G` - 降低
- 按 `R` - 回中（悬停）

**步骤 6：降落**
- 按 `R` 全部回中（先稳定悬停）
- 按 `2` 发送降落命令

---

### 流程二：QGC 虚拟摇杆控制

```
步骤 1: 启动 PX4 SITL + DDS Agent
步骤 2: 启动 QGC (DDS_P3 分支编译版)
步骤 3: 设置页 Add 无人机 → Connect
步骤 4: 回到飞行界面
步骤 5: 点击起飞按钮
步骤 6: 切换到 Position 模式
步骤 7: 操作虚拟摇杆控制飞行
步骤 8: 点击降落按钮
```

**详细步骤：**

**步骤 1-3：连接**（与之前测试相同）

**步骤 4：确认虚拟摇杆已启用**
- 齿轮 → General → Virtual Joystick = ON
- 回到飞行界面，底部应出现两个摇杆区域

**步骤 5：起飞**
- 点击飞行界面左侧工具栏的起飞按钮
- 滑动确认起飞
- 等待无人机上升到目标高度

**步骤 6：切换到 Position 模式**
- 点击工具栏顶部的飞行模式（如 "Hold"）
- 在下拉菜单中选择 **"Position"**
- Position 模式下 PX4 会接受手动控制输入

**步骤 7：操作虚拟摇杆**
- 拖动右摇杆控制前后左右
- 拖动左摇杆控制高度和偏航
- 松开摇杆会自动回中（Position 模式下无人机悬停）

**步骤 8：降落**
- 松开所有摇杆
- 点击降落按钮

## 7. 话题格式说明

### ManualControlSetpoint 字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| `timestamp` | uint64 | 0 | 设为 0，PX4 自动替换为 hrt_absolute_time() |
| `timestamp_sample` | uint64 | 0 | 同上 |
| `valid` | bool | true | 数据有效标志，**必须为 true** |
| `data_source` | uint8 | 2 | 2=SOURCE_MAVLINK_0（模拟 MAVLink 输入源）|
| `roll` | float32 | [-1, 1] | 横滚：-1=左满，0=中，+1=右满 |
| `pitch` | float32 | [-1, 1] | 俯仰：-1=前满（nose down），0=中，+1=后满 |
| `yaw` | float32 | [-1, 1] | 偏航：-1=逆时针，0=中，+1=顺时针 |
| `throttle` | float32 | [-1, 1] | 油门：-1=最低，0=中位（悬停），+1=最高 |
| `sticks_moving` | bool | true/false | 摇杆是否在移动 |

### 关键注意事项

1. **throttle 范围是 [-1, 1]**，不是 [0, 1]！
   - QGC 虚拟摇杆内部 thrust=[0,1]，DDSManualControlPublisher 已做 `throttle = thrust * 2 - 1` 转换
   - 脚本/ros2 topic pub 直接填 [-1, 1]

2. **timestamp 必须为 0**
   - PX4 的 ucdr_deserialize 在 timestamp=0 时自动替换为 `hrt_absolute_time()`
   - 避免 QGC 挂钟时间与 PX4 仿真时间不同步导致消息被丢弃

3. **data_source 必须为 2**
   - PX4 的 ManualControlSelector 根据 data_source 判断输入来源
   - 2=SOURCE_MAVLINK_0 是 DDS/MAVLink 外部输入的标准值

4. **发布频率必须 ≥ 10Hz**
   - PX4 对 manual_control_input 有超时检测
   - 如果输入中断超过几秒，PX4 会触发 RC Lost 保护
   - 建议 25Hz（与真实遥控器相同）

5. **必须在 Position 模式下**
   - PX4 起飞后通常进入 Hold/Loiter 模式
   - Hold 模式不接受手动控制输入
   - 必须切换到 Position（或 Altitude/Stabilized/Manual）模式

## 8. PX4 端验证命令

在 PX4 nsh 终端（`pxh>`）中执行：

### 查看是否收到手动控制输入
```bash
listener manual_control_input
```

预期输出：
```
TOPIC: manual_control_input
  timestamp: 12345678
  timestamp_sample: 12345678
  valid: True
  data_source: 2
  roll: 0.300
  pitch: -0.200
  yaw: 0.000
  throttle: 0.500
  sticks_moving: True
```

如果 roll/pitch/yaw/throttle 全为 0 且不随摇杆移动变化 → QGC 端没有正确发送变化的值。

### 查看手动控制选择器状态
```bash
listener manual_control_setpoint
```

### 查看当前飞行模式
```bash
commander status
```

### 切换飞行模式
```bash
commander mode posctl    # Position 模式
commander mode altctl    # Altitude 模式
commander mode manual    # Manual 模式（仅固定翼）
commander mode auto:rtl  # 返航
commander mode auto:land # 降落
```

### 查看 RC 输入模式参数
```bash
param show COM_RC_IN_MODE
```

| 值 | 含义 |
|----|------|
| 0 | RC and MAVLink (默认，✅) |
| 1 | MAVLink only (✅) |
| 4 | Disabled (❌ 拒绝所有手动输入) |

如果值为 4，修改为 0：
```bash
param set COM_RC_IN_MODE 0
```

## 9. 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| `ros2 topic list` 看不到话题 | DDS Agent 未启动 | 启动 MicroXRCEAgent |
| 话题存在但 `listener` 无数据 | QoS 不匹配 | 确认使用 BEST_EFFORT + VOLATILE |
| PX4 收到数据但不响应 | 不在 Position 模式 | `commander mode posctl` |
| PX4 收到数据但不响应 | COM_RC_IN_MODE=4 | `param set COM_RC_IN_MODE 0` |
| QGC 虚拟摇杆值始终为 0 | thumbDown() 触摸跟踪 bug | 确认使用最新 DDS_P3 代码 |
| QGC 日志无摇杆输出 | Timer 未启动 | 检查 Virtual Joystick 设置是否开启 |
| 起飞后无法手动控制 | 还在 Takeoff/Hold 模式 | 切换到 Position 模式 |
| 摇杆停止后无人机失控 | RC Lost 保护触发 | 保持持续发送，或设置 COM_RCL_EXCEPT 参数 |
| pitch 方向反了 | PX4 pitch 约定 | pitch<0=前进(nose down), pitch>0=后退 |
