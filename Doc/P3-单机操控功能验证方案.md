# P3 - 单机操控功能验证方案

## 目的

验证 QGC DDS 版本的飞行操控功能是否通过 DDS command 通道正常工作。
这些功能在原版 QGC 中通过 MAVLink 发送 `MAV_CMD_*` 命令实现，
DDS 版本中 `sendMavCommand()` / `sendMavCommandInt()` 已自动路由到
`DDSCommandPublisher` → `fmu/in/vehicle_command`，理论上无需额外代码即可工作。

---

## 测试环境

| 项目 | 配置 |
|------|------|
| PX4 | v1.17.0-alpha, SITL gz_x500 |
| DDS Agent | MicroXRCE-DDS Agent (UDP) |
| QGC | DDS_P3 分支 |
| 测试工具 | `Doc/test_guided_actions.py` 或 QGC 界面 |

## 测试用例

### TC-01: 暂停 (Pause)

**命令**: `MAV_CMD_DO_REPOSITION` (192)

**参数**:
| param | 值 | 含义 |
|-------|---|------|
| param1 | -1.0 | 地速不变 |
| param2 | 1.0 | MAV_DO_REPOSITION_FLAGS_CHANGE_MODE |
| param3-7 | NaN | 保持当前位置 |

**前置条件**: 无人机在空中飞行中（已起飞，在移动状态）

**操作步骤**:
1. 起飞到 5m 高度
2. 使用虚拟摇杆或 Go To 让无人机移动
3. **脚本**: 输入 `1`（暂停）
4. **QGC**: 点击飞行界面左侧 **Pause** 按钮

**预期效果**:
- PX4 `nav_state` 变为 `AUTO_LOITER` (4) 或 `POSCTL` (2)
- 无人机停止移动，在当前位置悬停
- QGC 工具栏显示 "Hold" 或 "Position"
- PX4 终端日志应有 `nav_state` 变化

**PX4 验证**:
```bash
# 在 pxh> 终端
commander status  # 查看当前模式
```

**ros2 命令行测试**:
```bash
ros2 topic pub --once /fmu/in/vehicle_command px4_msgs/msg/VehicleCommand \
  "{timestamp: 0, command: 192, param1: -1.0, param2: 1.0, \
    target_system: 1, target_component: 1, source_system: 255, from_external: true}"
```

### TC-02: 改变高度

**命令**: `MAV_CMD_DO_REPOSITION` (192)

**参数**:
| param | 值 | 含义 |
|-------|---|------|
| param1 | -1.0 | 地速不变 |
| param2 | 1.0 | MAV_DO_REPOSITION_FLAGS_CHANGE_MODE |
| param5 | 当前纬度 | 保持当前纬度 |
| param6 | 当前经度 | 保持当前经度 |
| param7 | 当前AMSL高度 + 3.0 | **新目标高度 (AMSL)** |

**前置条件**: 无人机在空中悬停

**操作步骤**:
1. 起飞到 5m
2. 记录当前高度
3. **脚本**: 输入 `2`（改变高度 +3m）
4. **QGC**: 点击飞行界面 **Change Altitude**，滑动到目标高度

**预期效果**:
- 无人机从当前高度上升约 3m
- QGC 高度显示从 ~5m 变为 ~8m
- PX4 `vehicle_global_position.alt` 增加约 3m
- 无人机水平位置不变

**PX4 验证**:
```bash
listener vehicle_global_position  # 查看 alt 字段变化
```

**ros2 命令行测试**（假设当前 AMSL 高度 = 493m）:
```bash
ros2 topic pub --once /fmu/in/vehicle_command px4_msgs/msg/VehicleCommand \
  "{timestamp: 0, command: 192, param1: -1.0, param2: 1.0, \
    param5: 47.397742, param6: 8.545594, param7: 496.0, \
    target_system: 1, target_component: 1, source_system: 255, from_external: true}"
```

### TC-03: 改变速度

**命令**: `MAV_CMD_DO_CHANGE_SPEED` (178)

**参数**:
| param | 值 | 含义 |
|-------|---|------|
| param1 | 1.0 | 速度类型: 1=地速 |
| param2 | 3.0 | 目标速度 (m/s) |
| param3 | -1.0 | 油门不变 |
| param4 | 0.0 | 绝对速度（非相对） |

**前置条件**: 无人机在空中

**操作步骤**:
1. 起飞到 5m
2. **脚本**: 输入 `3`（改变速度 3 m/s）
3. **QGC**: 点击飞行界面 **Change Speed** 按钮，输入目标速度
4. 然后用虚拟摇杆或 Go To 让无人机移动，观察速度

**预期效果**:
- PX4 接受速度变更命令 (ACK=0)
- 后续飞行的地速被限制在约 3 m/s
- QGC 速度显示不超过 ~3 m/s（在 Position 模式下移动时）

**PX4 验证**:
```bash
listener vehicle_local_position  # 查看 vx, vy 字段
# 计算地速: sqrt(vx^2 + vy^2) 应 ≤ 3 m/s
```

**ros2 命令行测试**:
```bash
ros2 topic pub --once /fmu/in/vehicle_command px4_msgs/msg/VehicleCommand \
  "{timestamp: 0, command: 178, param1: 1.0, param2: 3.0, param3: -1.0, param4: 0.0, \
    target_system: 1, target_component: 1, source_system: 255, from_external: true}"
```

**注意**: 此命令对当前 PX4 版本的多旋翼可能不生效（PX4 多旋翼速度由 MPC_XY_VEL_MAX 参数控制，DO_CHANGE_SPEED 主要影响 auto 模式下的航线速度）。测试时需注意这个限制。

### TC-04: 改变航向

**命令**: `MAV_CMD_DO_REPOSITION` (192)

**参数**:
| param | 值 | 含义 |
|-------|---|------|
| param1 | -1.0 | 地速不变 |
| param2 | 1.0 | MAV_DO_REPOSITION_FLAGS_CHANGE_MODE |
| param4 | 1.5708 | 目标航向 (弧度)，90° = π/2 |
| param5 | 当前纬度 | 保持当前位置 |
| param6 | 当前经度 | 保持当前位置 |
| param7 | 当前AMSL高度 | 保持当前高度 |

**前置条件**: 无人机在空中悬停

**操作步骤**:
1. 起飞到 5m，悬停
2. 记录当前航向（通常初始为北 0°）
3. **脚本**: 输入 `4`（改变航向到 90°/东）
4. **QGC**: 在飞行界面长按地图 → 选择 **Change Heading** → 拖动到目标方向

**预期效果**:
- 无人机原地旋转，机头转向东方（90°）
- QGC 姿态球/HUD 的 yaw 值变为约 90°
- 无人机水平位置和高度不变

**PX4 验证**:
```bash
listener vehicle_attitude  # 查看 yaw 字段（弧度）
# yaw ≈ 1.57 rad = 90°
```

**ros2 命令行测试**:
```bash
ros2 topic pub --once /fmu/in/vehicle_command px4_msgs/msg/VehicleCommand \
  "{timestamp: 0, command: 192, param1: -1.0, param2: 1.0, \
    param4: 1.5708, param5: 47.397742, param6: 8.545594, param7: 488.0, \
    target_system: 1, target_component: 1, source_system: 255, from_external: true}"
```

### TC-05: 绕点飞行 (Orbit)

**命令**: `MAV_CMD_DO_ORBIT` (34)

**参数**:
| param | 值 | 含义 |
|-------|---|------|
| param1 | 10.0 | 半径 (m)，正值=顺时针，负值=逆时针 |
| param2 | NaN | 使用默认速度 |
| param3 | 0.0 | ORBIT_YAW_BEHAVIOUR_HOLD_FRONT_TO_CIRCLE_CENTER |
| param4 | NaN | 使用默认圈数（无限） |
| param5 | 当前纬度 | 圆心纬度 |
| param6 | 当前经度 | 圆心经度 |
| param7 | 当前AMSL高度 | 飞行高度 |

**前置条件**: 无人机在空中悬停

**操作步骤**:
1. 起飞到 5m
2. **脚本**: 输入 `5`（Orbit 半径 10m）
3. **QGC**: 在飞行界面长按地图 → 选择 **Orbit** → 设置半径

**预期效果**:
- PX4 `nav_state` 变为 `ORBIT` (21)
- 无人机以当前位置为圆心，半径 10m 绕圈飞行
- 机头始终朝向圆心
- QGC 地图显示圆形轨迹

**PX4 验证**:
```bash
commander status  # 应显示 Orbit 模式
listener vehicle_global_position  # lat/lon 应在圆形轨迹上变化
```

**ros2 命令行测试**:
```bash
ros2 topic pub --once /fmu/in/vehicle_command px4_msgs/msg/VehicleCommand \
  "{timestamp: 0, command: 34, param1: 10.0, \
    param5: 47.397742, param6: 8.545594, param7: 488.0, \
    target_system: 1, target_component: 1, source_system: 255, from_external: true}"
```

**注意**: Orbit 功能需要 PX4 编译时启用 `mc_orbit` 模块。SITL 默认应已包含。如 PX4 返回 `UNSUPPORTED`，表示该固件不支持。

### TC-06: 紧急停机 (Emergency Stop)

**命令**: `MAV_CMD_COMPONENT_ARM_DISARM` (400)

**参数**:
| param | 值 | 含义 |
|-------|---|------|
| param1 | 0.0 | Disarm |
| param2 | 21196.0 | Magic number for force disarm |

**前置条件**: 无人机在空中（Armed + Flying）

**操作步骤**:
1. 起飞到 5m
2. **脚本**: 输入 `6`（需确认）
3. **QGC**: 飞行界面工具栏 → 点击 Armed → 长按 **Emergency Stop** 滑块

**预期效果**:
- ⚠️ **无人机立即停止所有电机，自由坠落！**
- PX4 `arming_state` 立即变为 `STANDBY` (1)
- QGC 显示 "Disarmed"
- 在仿真中无人机会直接掉到地面

**PX4 验证**:
```bash
commander status  # arming_state = Standby
```

**ros2 命令行测试**:
```bash
ros2 topic pub --once /fmu/in/vehicle_command px4_msgs/msg/VehicleCommand \
  "{timestamp: 0, command: 400, param1: 0.0, param2: 21196.0, \
    target_system: 1, target_component: 1, source_system: 255, from_external: true}"
```

**⚠️ 警告**: 在真实飞行中使用紧急停机会导致无人机坠毁！仅在紧急情况下使用。仿真中可安全测试。

## 推荐测试流程

```
1. 启动 PX4 + DDS Agent + 测试脚本
2. 按 'a' ARM → 按 'c' TAKEOFF (5m)
3. 等待起飞完成 (约 10 秒)
4. 按 '7' 测试 Go To (向北飞)
5. 按 '1' 测试 Pause (悬停)
6. 按 '2' 测试 Change Altitude (+3m)
7. 按 '4' 测试 Change Heading (90°)
8. 按 '5' 测试 Orbit
9. 按 '1' 再次 Pause (停止 Orbit)
10. 按 '3' 测试 Change Speed
11. 按 'd' 降落
12. 重新起飞
13. 按 '6' 测试 Emergency Stop (仅仿真！)
```

## 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 命令无 ACK | writer 未匹配 PX4 reader | 检查 DDS Agent 是否运行，`ros2 topic list` 是否有 vehicle_command |
| ACK result ≠ 0 | PX4 拒绝命令 | 查看 PX4 终端错误信息 |
| Pause 无效 | 不在可暂停的模式中 | 先让无人机移动（Go To 或摇杆），再暂停 |
| Orbit 不支持 | PX4 固件未编译 mc_orbit | 检查 `commander status`，如返回 UNSUPPORTED 则固件不支持 |
| 改变速度无效 | 多旋翼 DO_CHANGE_SPEED 限制 | PX4 多旋翼 Position 模式速度由 MPC_XY_VEL_MAX 参数控制 |
| 改变高度不准确 | AMSL 高度计算偏差 | 确保使用 AMSL（不是相对高度），脚本自动获取当前 AMSL |
| Emergency Stop 被拒 | param2 magic number 错误 | 确认 param2=21196.0 |
