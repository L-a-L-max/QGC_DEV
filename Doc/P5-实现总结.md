## 二、P5-1 虚拟摇杆增强

### 新增配置项（AppSettings）

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| virtualJoystickMaxSpeed | double | 12.0 | 1.0-20.0 | 最大飞行速度 (m/s) |
| virtualJoystickDeadzone | double | 0.05 | 0.0-0.3 | 中心死区比例 |
| virtualJoystickExpo | double | 0.0 | 0.0-0.8 | 指数曲线系数 |

### 摇杆曲线算法

```
输入: raw_input [-1, 1]
1. 死区过滤: |input| < deadzone → 0
2. 归一化: normalized = (|input| - deadzone) / (1 - deadzone)
3. 指数曲线: curved = (1-expo)*normalized + expo*normalized³
4. 速度缩放: output = curved * (maxSpeed / 12.0)
```

## 三、P5-2 GotoSetpoint Publisher

### IDL 定义 (`src/DDS/idl/GotoSetpoint.idl`)

```idl
struct GotoSetpoint_ {
    unsigned long long timestamp;
    float position[3];              // NED 坐标 [m]
    boolean flag_control_heading;
    float heading;                  // [rad] [-π, π]
    boolean flag_set_max_horizontal_speed;
    float max_horizontal_speed;     // [m/s]
    boolean flag_set_max_vertical_speed;
    float max_vertical_speed;       // [m/s]
    boolean flag_set_max_heading_rate;
    float max_heading_rate;         // [rad/s]
};
```

### NED 坐标转换

```
north = (lat - home_lat) * DEG_TO_RAD * EARTH_RADIUS
east  = (lon - home_lon) * DEG_TO_RAD * EARTH_RADIUS * cos(home_lat)
down  = home_alt - target_alt
```

### PX4 Topic

- 输入: `fmu/in/goto_setpoint`
- QoS: BEST_EFFORT + VOLATILE

## 四、P5-3 航点任务状态机

### 状态

```
Idle → Running → [Hovering] → Running → ... → Complete → EndAction
         ↑           |
         └── Paused ←┘
```

| 状态 | 触发条件 | 行为 |
|------|---------|------|
| Idle | 初始/stopMission | 不发送任何命令 |
| Running | startMission/resume | 发送 goto_setpoint，5Hz 检测到达 |
| Paused | pauseMission | 停止发送，保持当前位置 |
| Hovering | 到达航点+有悬停时间 | 等待 hoverTime 后自动前进 |
| Complete | 最后一个航点到达 | 执行结束动作 |

### 到达检测

- 水平距离 < 2.0m
- 垂直距离 < 1.5m
- 检测频率: 5Hz (200ms)
- goto 重发频率: 每 2 秒

右侧面板，通过 FlyView 的 "Mission" 按钮切换显示。

- 右键菜单新增 "Add DDS Waypoint" 选项
- 青色折线连接所有航点
- 数字标记显示航点位置（当前航点高亮）

## 六、P5-5 任务结束动作

| 动作 | 实现 |
|------|------|
| Hover (悬停) | 不发送额外命令，保持最后位置 |
| RTL (返航) | MAV_CMD_NAV_RETURN_TO_LAUNCH (20) |
| Land (降落) | MAV_CMD_NAV_LAND (21) |

用户在 DDSPlanPanel 中通过下拉框选择。

## 七、P5-6 飞行轨迹修复

**问题**: DDS 车辆的飞行轨迹不显示在地图上。

**原因**: DDSDataInjector 直接设置 `_vehicle->_armed` 而不调用 `_updateArmed()`，导致 `TrajectoryPoints::start()` 从未被调用。

**修复**: 在 DDSDataInjector 的 armed 状态变更处，添加 `trajectoryPoints()->start()/stop()` 调用。

### 9.2 QGC 界面测试

1. 启动 PX4 SITL + XRCE Agent + QGC
2. 连接 DDS 车辆
3. 点击界面右上角 "Mission" 按钮打开规划面板

5. 设置高度、速度、结束动作
6. 起飞后点击 "Start" 开始任务
