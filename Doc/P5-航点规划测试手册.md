# P5 航点规划功能测试手册

## 环境准备

### 终端 1：启动 PX4 SITL
```bash
cd ~/PX4-Autopilot
make px4_sitl gz_x500
```

### 终端 2：启动 XRCE-DDS Agent
```bash
MicroXRCEAgent udp4 -p 8888
```

### 终端 3：启动 QGC
```bash
cd ~/qgc_build   # 你的构建目录
./QGroundControl
```

等待 QGC 连接到 DDS 无人机（顶部状态栏显示 "Ready" 或 "定点Position"）。

---

## 测试一：Mission 面板显示

### 步骤
1. 确认 QGC 已连接到 DDS 无人机（顶部显示飞行模式）
2. 点击飞行界面右上角 **"Mission"** 按钮

### 预期
- 右侧弹出 DDS Mission 面板
- 显示 "Status: Idle"
- "Add WP at Vehicle Pos" 按钮可点击（非灰色）
- 底部显示 Altitude/Speed/End Action 配置项

---

## 测试二：通过面板按钮添加航点

### 步骤
1. 打开 Mission 面板
2. 设置 Altitude 为 `15`（米）
3. 设置 Speed 为 `5`（m/s，-1 表示使用默认）
4. 点击 **"Add WP at Vehicle Pos"** 按钮

### 预期
- 航点列表出现 "WP1"，显示 15m 高度
- 地图上无人机位置附近出现青色航点标记
- 可重复点击添加多个航点

---

## 测试三：通过地图点击添加航点

### 步骤
1. 打开 Mission 面板
2. **左键单击**地图上任意位置
3. 弹出菜单中选择 **"Add DDS Waypoint"**

### 预期
- 弹出包含 "Add DDS Waypoint" 按钮的菜单
- 点击后航点列表新增一个航点（默认 10m 高度）
- 地图上该位置出现青色航点标记
- 航点之间自动显示青色连接线

### 注意
- 如果地图点击后没有弹出菜单：确认无人机已连接（需要 ddsMissionManager 已绑定）
- 弹出菜单可能还显示其他选项（Go to location, Orbit 等），取决于飞行状态

---

## 测试四：删除航点

### 步骤
1. 添加 2-3 个航点
2. 在航点列表中点击某个航点旁的 **"Del"** 按钮

### 预期
- 该航点从列表和地图上移除
- 航线连接线自动更新

---

## 测试五：执行航点任务

### 前置条件
- 无人机已起飞并处于空中
- 起飞方法：
  ```bash
  # 在 PX4 终端 (pxh>):
  commander takeoff
  ```
  或使用 QGC 界面的起飞按钮

### 步骤
1. 添加 2-3 个航点（不同位置，高度 10-20m）
2. 选择 End Action（Hover/RTL/Land）
3. 点击 **"Start"** 按钮

### 预期
- Status 变为 "Running"
- 当前航点在列表中高亮显示
- 面板显示到当前航点的距离
- 无人机依次飞向各航点
- 到达最后一个航点后执行 End Action：
  - Hover：悬停在最后航点位置
  - RTL：返航到 Home 点
  - Land：在当前位置降落

### PX4 验证
```bash
# 在 PX4 终端查看 goto_setpoint 是否收到
listener goto_setpoint
```

---

## 测试六：暂停/恢复任务

### 步骤
1. 任务执行中（Status: Running）
2. 点击 **"Pause"** 按钮
3. 等待几秒
4. 点击 **"Resume"** 按钮

### 预期
- Pause 后 Status 变为 "Paused"，无人机悬停
- Resume 后 Status 变为 "Running"，继续飞向当前航点

---

## 测试七：停止任务

### 步骤
1. 任务执行中
2. 点击 **"Stop"** 按钮

### 预期
- Status 变为 "Idle"
- 无人机悬停在当前位置
- 航点列表保留（可重新 Start）

---

## 测试八：保存/加载任务

### 保存步骤
1. 添加若干航点
2. 点击 **"Save"** 按钮
3. 选择保存路径，文件名以 `.ddsmission` 结尾

### 加载步骤
1. 点击 **"Clear"** 清空当前航点
2. 点击 **"Load"** 按钮
3. 选择之前保存的 `.ddsmission` 文件

### 预期
- 保存的文件为 JSON 格式
- 加载后航点列表和地图标记恢复

---

## 测试九：虚拟摇杆参数配置

### 步骤
1. 进入 QGC 设置 → General
2. 找到 Virtual Joystick 相关设置项：
   - **Max Speed**：1-20 m/s（默认 12）
   - **Deadzone**：0-0.3（默认 0.05）
   - **Expo**：0-0.8（默认 0）
3. 修改参数后返回飞行界面
4. 起飞后切换到 Position 模式（`commander mode posctl`）
5. 操作虚拟摇杆

### 预期
- Max Speed 降低后，摇杆推到底时飞行速度降低
- Deadzone 增大后，摇杆小幅移动不响应
- Expo 增大后，摇杆中心附近更灵敏（非线性响应）

## 故障排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| Mission 按钮不可见 | 无人机未连接 | 等待 DDS 连接完成 |
| "Add WP at Vehicle Pos" 灰色 | GPS 坐标无效或 MissionManager 未绑定 | 等待 GPS 锁定，检查日志 |
| 点击地图无菜单弹出 | ddsMissionManager 未就绪 | 等 DDS 连接稳定后重试 |
| 航点不显示在地图上 | QML 绑定未更新 | 添加/删除航点触发刷新 |
| Start 无响应 | 无人机未起飞 | 先执行起飞命令 |
| PX4 不响应 goto_setpoint | 未进入正确模式 | PX4 收到 goto 后应自动切换模式 |
