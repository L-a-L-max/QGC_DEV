# P3 测试方案

## 测试环境

| 项目 | 配置 |
|------|------|
| PX4 | v1.17.0-alpha, SITL 或实机 |
| PX4 DDS Agent | MicroXRCE-DDS Agent (UDP 模式) |
| QGC | DDS_P3 分支编译 |
| 网络 | 同一局域网，DDS Domain 0 |
| 测试机器 | ros2-0 (已验证可连接) |

---

## 测试用例

### TC-01: DDS Writer 初始化

**前置条件**: QGC 启动并通过 DDS 发现 PX4 Agent

**步骤**:
1. 启动 QGC
2. 等待 DDS 连接建立（Vehicle 创建）
3. 检查日志

**预期结果**:
```
[DDSCommandPublisher] Writer created for topic: rt/fmu/in/vehicle_command
[DDSCommandPublisher] Writer matched with PX4 reader
```

**验证命令**:
```bash
./QGroundControl 2>&1 | grep -i "CommandPublisher\|writer"
```

---

### TC-02: 解锁 (Arm)

**前置条件**: QGC 已连接，飞机处于 Disarmed 状态

**步骤**:
1. 在 QGC 界面点击工具栏 → Armed/Disarmed 状态区域
2. 确认解锁滑块/按钮
3. 观察飞机状态变化

**预期结果**:
- QGC 日志: `[DDSCommandPublisher] Sent command 400 (ARM_DISARM) param1=1.0`
- PX4 状态变化: `arming_state` 从 1 (STANDBY) 变为 2 (ARMED)
- QGC 工具栏显示 "Armed"
- SITL: 电机声音/指示灯变化

**失败检查**:
- 如果 PX4 拒绝解锁，ACK result ≠ 0
- QGC 应显示错误提示

---

### TC-03: 上锁 (Disarm)

**前置条件**: 飞机已解锁 (Armed)，在地面

**步骤**:
1. 点击 Disarm 按钮
2. 确认上锁

**预期结果**:
- `arming_state` 变为 1 (STANDBY)
- QGC 工具栏显示 "Disarmed"

---

### TC-04: 起飞 (Takeoff)

**前置条件**: 飞机在地面，已 Disarmed 或 Armed

**步骤**:
1. 点击 Takeoff 操作
2. 设置目标高度（如 5m）
3. 确认起飞

**预期结果**:
- QGC 发送 MAV_CMD_NAV_TAKEOFF (22)
- 飞机自动解锁 → 起飞到指定高度
- `nav_state` 变为 Takeoff 状态
- 高度读数增加到目标值附近
- QGC 显示飞行模式为 "Takeoff"

---

### TC-05: 模式切换 (Mode Change)

**前置条件**: 飞机已解锁，悬停中

**步骤**:
1. 点击工具栏飞行模式选择器
2. 选择 "Position" / "Hold" / "RTL" 等模式
3. 观察模式变化

**预期结果**:
- QGC 发送 MAV_CMD_DO_SET_MODE (176)
- PX4 `nav_state` 变化
- QGC 工具栏模式显示更新

**测试模式列表**:
- Manual → Position
- Position → Hold
- Hold → RTL
- Position → Land

---

### TC-06: 降落 (Land)

**前置条件**: 飞机在空中

**步骤**:
1. 点击 Land 按钮
2. 确认降落

**预期结果**:
- 飞机切换到 Land 模式
- 高度逐渐降低
- 着地后自动上锁
- `vehicle_land_detected.landed = true`
- QGC 显示 "Landed" → "Disarmed"

---

### TC-07: 返航 (RTL)

**前置条件**: 飞机在空中，距离 Home 点有一定距离

**步骤**:
1. 点击 RTL 按钮
2. 确认返航

**预期结果**:
- 飞机切换到 RTL 模式
- 飞机向 Home 点飞行
- 到达后降落并上锁

---

### TC-08: 命令 ACK 接收

**前置条件**: QGC 订阅了 vehicle_command_ack

**步骤**:
1. 发送任意命令（如 Arm）
2. 观察 ACK 反馈

**预期结果**:
- 收到 ACK: `command=400, result=0 (ACCEPTED)`
- 日志: `[DDSDataInjector] Command ACK: cmd=400 result=ACCEPTED`

**失败场景测试**:
- 在飞行中尝试 Disarm → 应收到 `result=2 (DENIED)`
- QGC 应显示错误消息

---

### TC-09: 就绪状态显示

**前置条件**: QGC 连接正常

**步骤**:
1. 观察工具栏状态区域
2. 检查是否显示 "Ready to Fly" 或传感器状态

**预期结果**:
- 当 `arming_state == 1 (STANDBY)` 时显示 "Ready to Fly"
- 工具栏不再显示 "Not Ready"（除非传感器确实异常）

---

### TC-10: 命令超时处理

**前置条件**: QGC 连接正常

**步骤**:
1. 断开 PX4 Agent（模拟通信丢失）
2. 尝试发送命令

**预期结果**:
- 命令发送后 3 秒无 ACK
- QGC 显示命令超时提示
- 不会无限等待

## 编译与运行

```bash
# 拉取 P3 代码
cd ~/QGC_DDS/qgc_dev
git fetch origin DDS_P3
git checkout DDS_P3

# 编译（增量）
cd build
ninja -j$(nproc)

# 运行测试
./QGroundControl 2>&1 | tee /tmp/qgc_p3_test.log

# 检查命令发送日志
grep -E "CommandPublisher|command_ack|sendCommand" /tmp/qgc_p3_test.log
```

## 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| Writer 创建失败 | IDL 类型不匹配 | 检查 VehicleCommand.idl 字段与 PX4 msg 一致 |
| 命令发送无响应 | Writer 未匹配 PX4 reader | 确认 PX4 Agent 订阅了 `/fmu/in/vehicle_command` |
| ACK 不到达 | PX4 未发布 ACK 话题 | 确认 dds_topics.yaml 包含 `/fmu/out/vehicle_command_ack` |
| 解锁被拒绝 | from_external 未设置 | 确认命令中 `from_external = true` |
| 模式切换无效 | custom_mode 编码错误 | 确认 px4_custom_mode 编码正确 |
