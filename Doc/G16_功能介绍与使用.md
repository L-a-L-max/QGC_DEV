# G16 遥控器映射功能介绍与使用

## 功能概述

本功能将 Skydroid G16 遥控器的摇杆输入映射到 QGC 的虚拟摇杆通道，通过标准 MAVLink `MANUAL_CONTROL` 消息发送到飞控。

**不修改 QGC 官方源码的任何已有功能**，仅在官方代码基础上追加 G16 集成模块。

## 架构设计

```
┌─────────────────────────────────────────────────────────────────┐
│                        QGC Android APK                           │
│                                                                  │
│  ┌──────────────────┐    JNI    ┌────────────────────────┐      │
│  │SkydroidRCSDKManager│◄────────│  G16JoystickPlugin     │      │
│  │    (Java/RCSDK)   │─────────►│     (C++/QObject)      │      │
│  │                   │          │                        │      │
│  │ • SDK 初始化      │          │ • 读取通道值 (20Hz)    │      │
│  │ • RC 连接管理     │          │ • 归一化 [-1,1]/[0,1]  │      │
│  │ • 通道值轮询      │          │ • 调用虚拟摇杆接口     │      │
│  └──────────────────┘          └───────────┬────────────┘      │
│                                             │                    │
│                                             ▼                    │
│                          Vehicle::virtualTabletJoystickValue()   │
│                                             │                    │
│                                             ▼                    │
│                           MAVLink MANUAL_CONTROL (msg #69)       │
│                                             │                    │
└─────────────────────────────────────────────┼────────────────────┘
                                              │ WiFi/USB/Serial
                                              ▼
                                     PX4 / ArduPilot 飞控
```

## 数据流

1. **G16 遥控器** → USB/蓝牙 → Android 设备
2. **SkydroidRCSDKManager** (Java) 以 100ms 间隔轮询 16 个通道值（范围 1000-2000）
3. **G16JoystickPlugin** (C++) 每 50ms 通过 JNI 读取通道值
4. 归一化处理：
   - Roll/Pitch/Yaw: `[1000, 2000]` → `[-1.0, +1.0]`（中心 1500 = 0）
   - Throttle: `[1000, 2000]` → `[0.0, 1.0]`
5. 调用 `Vehicle::virtualTabletJoystickValue()` → 发送 MAVLink MANUAL_CONTROL

## 使用方法

### 1. 连接 G16 遥控器

将 Skydroid G16 遥控器通过 USB 或蓝牙连接到 Android 设备。

### 2. 启动 QGC

启动 QGroundControl，等待飞控连接成功。

### 3. 启用 G16 映射

在飞行视图的右下角，可以看到 **G16 Remote** 浮动面板：

```
┌─────────────────┐
│  G16 Remote  🟢 │  ← 绿色 = 已连接，红色 = 未连接
│  Mapping [开关]  │  ← 开关控制映射是否生效
│  rc connected   │  ← 状态文字
└─────────────────┘
```

- **绿色圆点**：G16 遥控器已连接
- **红色圆点**：G16 遥控器未连接
- **Mapping 开关**：控制是否将 G16 摇杆数据发送到飞控

### 4. 操控

开关打开后，移动 G16 摇杆即可控制飞机。默认通道映射（Mode 2）：

| 摇杆 | 通道 | 功能 | 范围 |
|------|------|------|------|
| 右摇杆 X | CH1 | Roll (横滚) | -1.0 ~ +1.0 |
| 右摇杆 Y | CH2 | Pitch (俯仰) | -1.0 ~ +1.0 |
| 左摇杆 Y | CH3 | Throttle (油门) | 0.0 ~ 1.0 |
| 左摇杆 X | CH4 | Yaw (偏航) | -1.0 ~ +1.0 |

### 5. 与屏幕虚拟摇杆的关系

- G16 映射和屏幕虚拟摇杆**可以同时使用**
- 两者都通过 `virtualTabletJoystickValue()` 发送，后发的数据覆盖先发的
- 如果只想用 G16，可以在 QGC 设置中关闭虚拟摇杆显示（Application Settings → Virtual Joystick = OFF），G16 面板仍然独立工作

## PX4 飞控配置

确保以下参数正确设置：

| 参数 | 值 | 说明 |
|------|----|------|
| `COM_RC_IN_MODE` | 1 或 3 | 1=Joystick优先, 3=RC或Joystick保持先到的 |
| `MAN_ARM_GESTURE` | 0 | 禁用摇杆解锁手势（推荐） |

如果没有连接实体 RC 遥控器（SBUS/PPM），设置 `COM_RC_IN_MODE = 1`。

## 注意事项

1. **仅 Android 平台**：G16 面板仅在 Android 上显示，桌面端不可用
2. **空闲不发送**：所有摇杆在 5% 死区内时不发送数据，避免干扰自动模式
3. **需要先连接飞控**：只有 activeVehicle 存在时才会发送 MANUAL_CONTROL
4. **MAVLink 标准协议**：完全兼容所有 MAVLink 飞控（PX4/ArduPilot）
5. **不依赖 DDS**：与之前 DDS_P5_V3 分支不同，本分支使用标准 MAVLink 通信

## 与 DDS_P5_V3 分支的对比

| 对比项 | DDS_P5_V3 | mavlink_G16（本分支） |
|--------|-----------|---------------------|
| 基础代码 | 自定义 fork | 官方最新 master |
| 通信协议 | CycloneDDS | MAVLink（官方标准） |
| G16 数据发送方式 | DDSManualControlPublisher | Vehicle::virtualTabletJoystickValue → MAVLink |
| 飞控兼容性 | 仅支持 DDS-enabled PX4 | 所有 MAVLink 飞控 |
| 官方代码侵入度 | 大量改动 | 极小（4 个文件各追加 1-3 行） |
